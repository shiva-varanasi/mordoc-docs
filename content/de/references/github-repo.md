title: Quell-Repositories
description: Verweise auf die offiziellen Mordoc-Quellcode-Repositories.
---

Mordoc ist ein Open-Source-Projekt. Der Quellcode ist auf mehrere Repositories aufgeteilt, jedes mit einem bestimmten Zweck.

# Mordoc Core

[github.com/mordoc](https://github.com/shiva-varanasi/mordoc)

Dieses Repository enthält das Mordoc-Kernframework, einschließlich Rendering-Logik, Konfigurationsverarbeitung und eingebauter Komponenten.

# Create Mordoc App

[github.com/create-mordoc-app](https://github.com/shiva-varanasi/create-mordoc-app)

Dieses Repository stellt einen schlanken Wrapper bereit, der ein neues Mordoc-Projekt initialisiert, indem es die Create-App-Funktionalität aus dem Mordoc-Kern aufruft.

# Mordoc Docs

[github.com/mordoc-docs](https://github.com/shiva-varanasi/mordoc-docs)

Dieses Repository enthält den Quellinhalt der Mordoc-Dokumentationswebsite selbst, geschrieben mit Mordoc.
