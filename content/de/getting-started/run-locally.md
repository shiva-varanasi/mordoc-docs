title: Lokal ausführen
description: Starten Sie den Mordoc-Entwicklungsserver und zeigen Sie Ihre Dokumentation im Browser als Vorschau an.
---

Das lokale Ausführen ermöglicht es Ihnen, Ihre Dokumentation in der Vorschau anzusehen, bevor Sie sie veröffentlichen. Dies ist die übliche Methode, um Seiten zu schreiben, zu überprüfen und anzupassen.

## Den Entwicklungsserver starten

Wenn Sie gerade ein Projekt erstellt haben, wechseln Sie zunächst in den generierten Ordner:

```bash
cd my-docs
```

Starten Sie dann den lokalen Server:

```bash
npm run dev
```

Dies startet einen lokalen Server, damit Sie die Dokumentationswebsite auf Ihrem Computer als Vorschau anzeigen können.

Wenn der Server startet, gibt Mordoc eine lokale URL in Ihrem Terminal aus. Sie sieht in der Regel so aus:

```text
http://localhost:5173/
```

Öffnen Sie diese URL in Ihrem Browser, um Ihre Dokumentationswebsite anzuzeigen.

Sie sollten die Starter-Dokumentationswebsite aus der Vorlage sehen. Das bestätigt, dass Ihr neues Mordoc-Projekt funktioniert.

## Den Server stoppen

Sie können den Server zunächst laufen lassen, während Sie weiterlesen. Wenn Sie ihn stoppen möchten, kehren Sie zum Terminal zurück und drücken Sie `Ctrl+C`.
