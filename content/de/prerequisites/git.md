## Was ist Git?

Git ist ein Versionsverwaltungssystem, das Ihnen hilft, Änderungen an Ihrer Dokumentation nachzuverfolgen, mit anderen zusammenzuarbeiten und Ihre Website zu veröffentlichen.

## Warum Git verwenden?

Git ist nicht zwingend erforderlich, um Mordoc zu betreiben, wird jedoch für echte Dokumentationsprojekte dringend empfohlen.

- **Versionsverlauf**: Jede Änderung an Ihrer Dokumentation nachverfolgen
- **Zusammenarbeit**: Gemeinsam mit Teammitgliedern an derselben Dokumentation arbeiten
- **Sicherung**: Ihre Dokumentation sicher in Remote-Repositories aufbewahren
- **Veröffentlichung**: Viele Hosting-Plattformen sind mit Git für automatische Deployments integriert

## Git herunterladen

1. Besuchen Sie die offizielle Git-Website: [https://git-scm.com/](https://git-scm.com/install/)

2. Laden Sie das Installationsprogramm für Ihr Betriebssystem herunter:

   * **Windows**: Windows-Installationsprogramm herunterladen
   * **macOS**: macOS-Installationsprogramm herunterladen
   * **Linux**: Verwenden Sie den Paketmanager Ihrer Distribution oder folgen Sie den Linux-Anweisungen auf der Website

## Git installieren

Führen Sie das Installationsprogramm aus und folgen Sie den empfohlenen Optionen.

{% callout type="note" title="Hinweis" %}
Für die meisten Benutzer sind die Standardeinstellungen ausreichend. Sie müssen während der Installation nichts anpassen.
{% /callout %}

## Installation überprüfen

Überprüfen Sie nach Abschluss der Installation, ob Git korrekt installiert wurde.

1. Öffnen Sie Ihren Code-Editor
2. Öffnen Sie das integrierte Terminal
3. Führen Sie den folgenden Befehl aus:

```bash
git --version
```

Wenn Git korrekt installiert ist, sollte eine Versionsnummer auf dem Bildschirm angezeigt werden.
