Um Inhalte zu erstellen und zu bearbeiten, benötigen Sie einen Code-Editor. Diese Anleitung behandelt Visual Studio Code, Sie können jedoch jeden beliebigen Editor oder jede integrierte Entwicklungsumgebung (IDE) verwenden.

## Visual Studio Code

Visual Studio Code (VS Code) ist ein kostenloser, quelloffener Code-Editor, der Ihnen das Schreiben von Inhalten erleichtert.

### VS Code herunterladen

1. Besuchen Sie [code.visualstudio.com](https://code.visualstudio.com/)
2. Laden Sie das Installationsprogramm für Ihr Betriebssystem herunter:
   - **Windows**: Windows-Installationsprogramm herunterladen
   - **macOS**: macOS-Installationsprogramm herunterladen
   - **Linux**: Passendes Paket herunterladen (.deb, .rpm oder .snap)

### VS Code installieren

Installieren Sie VS Code, indem Sie den empfohlenen Optionen im Installationsassistenten folgen.

## Nächster Schritt

Nachdem Sie einen Code-Editor installiert haben, fahren Sie fort mit:
