Mordoc gives you a working design by default. You do not need to write any CSS to have a working documentation site.

Most teams still want their docs to feel like their own, though. Basic customization covers the two changes that get you there fastest: an accent color that matches your brand and, optionally, a font family that matches it too. Both take minutes, neither requires knowing how the rest of the site is put together, and your site still looks clean and professional either way.

## What you can change here

* **Accent color**: one color, set once, that spreads automatically to links, buttons, active navigation states, and more.
* **Font family**: replace the default typeface for body text and code with your own.
